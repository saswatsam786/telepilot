How it works

One hub routes.
Your sessions do the work.

Built only on first-party Claude Code features: channels, background sessions, cross-session messaging and hooks. No servers.

01

You text it

Anthropic's official Telegram channel delivers your message to a small hub session on your Mac.

you @api run the tests
02

The hub routes

It messages a running session, resumes a stopped one, or starts a new one. It never does heavy work itself.

hub → api (running)
03

Sessions report back

Hooks post results and approval buttons straight to your chat, so no tokens are spent relaying.

api 128/128 pass ✅

Security

Remote control,
with guard rails.

Only you get in

The official pairing allowlist means only your account reaches the hub.

Permissions stay on

Risky actions wait for your tap. Codes are random, single-use and expiring.

Guard hooks

They block sudo, deleting / or ~, curl | sh, secret reads and edits to Claude settings.

Kill switch

/panic stops every session telepilot started and denies pending requests.
