telepilot
★ GitHub
Claude Code plugin · Telegram · iMessage · macOS

Your Claude Code,
in your pocket.

Text any Claude Code session from your phone. It does the work on your Mac, asks before anything risky with one-tap buttons, and texts you back.

❯ /plugin marketplace add saswatsam786/telepilot
❯ /plugin install telepilot@telepilot
❯ /telepilot:setup

🧭 Talk to any session

@api fix the build reaches a running session, resumes a stopped one, or /new starts one in any folder. The hub only routes, so it always answers quickly.

✅ One-tap approvals

Permission prompts arrive as yes / no buttons on your phone.

📬 Results come to you

Each session posts its own answer, with typing and "still working" pings.

💻 Your Mac, remotely

Screenshots, camera photos, apps, Shortcuts, clipboard, volume, battery, plus /unlock and /lock. Your password stays in the Keychain.

🎙 Voice notes

Transcribed locally with whisper.cpp.

🛡 Safe by default

Allowlist, guard hooks, single-use codes, /panic, /audit.

🪶 Zero servers

Everything runs on your Mac with first-party Claude Code features.
